One-Click Restore

From any successful backup log, click Restore, fill in the target DB name, hit go. Async via ir.cron — no HTTP timeout on multi-GB restores. Auto-detects encryption and downloads from local / SFTP / cloud as needed. Full restore history kept on each backup.

Built for Real Production Workloads

  • Strategy auto-recommendation: Detects your DB size, filestore size, and tmp disk space — recommends standard, split, or streaming mode with one-click "Use Recommended" button.
  • Split mode for huge filestores: DB dump + independent rclone sync of filestore. rclone's content-addressed sync transfers only new attachments — every backup after the first is incremental.
  • Streaming mode for tiny temp disk: pg_dump | encrypt | rclone rcat — zero-footprint pipe direct to cloud, with deadline-based timeout and proper stderr drain to prevent buffer deadlock.
  • Pre-flight disk checks: Refuses to start a backup that would fill the disk. Clear error message with available vs. required GB.
  • L3 maintenance windows + resource priority: Schedule heavy verification jobs to run only at 2–4 AM, with ionice -c 3 nice -n 10 wrapping so they yield to production traffic.

How Restore Works

  1. Open any successful backup log
  2. Click Restore from this backup
  3. Enter target DB name (suggested: {source}_restored_{date})
  4. Hit Start Restore — Pro spawns an async ir.cron job
  5. Watch progress live: download → decrypt (if encrypted) → restore
  6. Get email + chatter notification on completion

Installation

Pro depends on Texura DB Backup Lite (install both). System requirements:

  • pg_dump / pg_restore — PostgreSQL client tools (already with Odoo)
  • rclone — only if using cloud storage. Install: apt install rclone or brew install rclone
  • cryptography — already in Odoo's venv (no extra pip)
